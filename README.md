# Portfolio Starter

처음 포트폴리오를 만드는 사람을 위한 가벼운 시작 템플릿입니다. 개발자뿐 아니라 기획, 마케팅, 영업, 운영 등 다양한 직무에 사용할 수 있습니다.

## 시작하기

1. `profile.md`에 소개와 관심 직무를 적습니다.
2. `projects/template.md`를 복사해 프로젝트, 수업 과제, 동아리, 아르바이트, 인턴 경험을 정리합니다.
3. 지원 직무에 맞춰 필요한 내용만 골라 이력서나 포트폴리오로 다듬습니다.

경험이 많지 않아도 괜찮습니다. 무엇을 맡았고, 어떻게 판단하고 행동했으며, 무엇을 배웠는지 구체적으로 적어보세요.

## AI와 함께 쓰기

처음 자료를 정리할 때는 `START_HERE.md`의 프롬프트를 Gemini, ChatGPT, Claude, Codex 등에 붙여 넣으세요.

Codex에서 이 폴더를 열고 원하는 작업을 평소 말하듯 요청하면 됩니다.

- “이 경험을 읽고 내가 한 일과 결과가 잘 드러나게 정리해줘. 사실은 추가하지 마.”
- “이 프로젝트 설명을 마케팅 직무에 맞춰 다듬고, 근거가 부족한 부분은 표시해줘.”
- “포트폴리오 전체에서 중복되거나 서로 모순되는 내용이 있는지 봐줘.”

반복적인 정리와 초안은 **Luna**로 시작하면 충분합니다. 여러 경험을 비교하거나 중요한 제출 문장을 최종 검토할 때는 **Sol**을 선택하세요. 사용량은 모델과 작업 규모에 따라 달라집니다.

## 공개 전에 확인하기

- 이름, 연락처, 주소 등 개인 정보가 필요한 만큼만 포함됐는지 확인합니다.
- 회사·고객·학교의 비공개 자료나 허락받지 않은 사진을 넣지 않습니다.
- 성과 수치와 역할은 확인 가능한 사실만 적습니다.
- 외부 공개 전에는 본인이 최종 내용을 직접 확인합니다.

## 파일 안내

- `profile.md`: 기본 소개와 관심 직무
- `projects/template.md`: 경험 하나를 정리하는 복사 가능한 양식
- `AGENTS.md`: AI가 내용을 다룰 때 지킬 기준
- `START_HERE.md`: 여러 AI에서 공통으로 쓰는 시작 프롬프트
- `.gitignore`: 로컬 비공개 파일과 비밀값 제외 규칙
